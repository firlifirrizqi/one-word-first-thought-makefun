# One Word, First Thought

Entry for the Make.fun bounty [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8).

The program writes exactly one word — the first that comes to mind — to
`/output/entry.txt`:

```
petrichor
```

*Petrichor*: the scent of rain on dry earth. Surprising, vivid, and
specific — a word that calls up a clear image in a few letters.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
